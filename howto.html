INSTALL · 설치하기

기기에 설치하면, 앱처럼 바로 시작할 수 있습니다.

마이서브노트는 PWA 방식의 웹 앱입니다. 별도의 설치 파일 없이 브라우저에서 바로 사용할 수 있고, 홈 화면·Dock·바탕화면에 설치해 일반 앱처럼 실행할 수 있습니다.

권장 사용 환경

원활한 이용을 위해 Chrome · Edge · Safari 최신 버전 사용을 권장합니다. 오래된 브라우저에서는 일부 기능이 정상적으로 작동하지 않을 수 있습니다.

Android · Chrome 권장iPhone / iPad · Safari 권장Windows · Chrome / Edge 권장Mac · Safari / Chrome / Edge

※ Mac에서 Safari의 웹 앱 설치 기능을 사용하려면 macOS Sonoma 14 이상이 필요합니다.

Android 전용 앱은 Google Play 출시를 준비하고 있습니다.

ANDROID

Android

  1. Chrome에서 마이서브노트에 접속합니다.
  2. 주소창 오른쪽의 더보기(⋮)를 누릅니다.
  3. 홈 화면에 추가 → 설치를 선택합니다.
  4. 화면 안내에 따라 설치를 완료합니다.
iOS / iPadOS

iPhone · iPad

  1. Safari에서 마이서브노트에 접속합니다.
  2. 공유 버튼을 누릅니다.
  3. 홈 화면에 추가를 선택합니다.
  4. 웹 앱으로 열기를 켠 뒤 추가를 누릅니다.
WINDOWS

Windows PC

  1. Chrome 또는 Edge에서 마이서브노트에 접속합니다.
  2. 주소창의 앱 설치 아이콘을 누르거나 브라우저 메뉴를 엽니다.
  3. Chrome은 페이지를 앱으로 설치, Edge는 이 사이트를 앱으로 설치를 선택합니다.
  4. 설치를 눌러 완료합니다.
macOS

Mac

  1. Safari에서 마이서브노트에 접속합니다.
  2. 도구 막대의 공유 버튼을 누릅니다.
  3. Dock에 추가를 선택합니다.
  4. 추가를 누르면 Dock과 응용 프로그램에서 실행할 수 있습니다.

Safari 웹 앱: macOS Sonoma 14 이상
