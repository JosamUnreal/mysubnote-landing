마이서브노트 사용방법

처음 자료를 만드는 단계부터 카드·빈칸·스케치·오디오·직접 쓰기까지, 실제 화면을 기준으로 정리했습니다.

STEP 01 · 자료 만들기

과목을 만드는 네 가지 방법

빈 과목으로 직접 시작하거나, 문서·Excel·Anki 자료를 가져올 수 있습니다.

  • 빈 과목
  • 문서로 자동생성
  • Excel 일괄추가
  • Anki 파일 가져오기
문서 자동생성

PDF·DOCX·법령 자료에서 문제 초안 만들기

파일을 직접 불러오거나 법제처 검색을 이용할 수 있습니다. 여러 문서를 한 과목의 자료로 묶어 분석할 수도 있습니다.

STEP 02 · 학습하기

상황에 맞게 학습 방법을 바꿔보세요.

직접 쓰기 + AI 채점

문제를 보고 정답을 직접 써보는 출력 학습입니다. 필요할 때 AI 채점으로 맞은 부분·빠뜨린 부분·틀린 부분을 확인할 수 있습니다.

카드학습

목록형에서는 여러 문제와 힌트를 빠르게 훑고 필요한 정답을 확인할 수 있습니다. 카드형에서는 한 문제씩 크게 띄워 집중해서 반복하며, 오디오를 함께 재생해 이동·운동 중 자투리 시간에도 학습을 이어갈 수 있습니다.

  • 목록형 · 여러 문제와 힌트를 빠르게 훑기
  • 카드형 · 한 문제씩 크게 보고 반복하기
  • 카드형에서도 오디오 재생 가능
1 / 4

빈칸학습

전체 답안을 쓰기 부담스러울 때 핵심어부터 꺼내봅니다. AI로 만든 과목은 빈칸학습도 함께 생성되며, 원하는 위치로 직접 수정할 수 있습니다.

1 / 2

오디오 학습

직접 녹음한 파일을 불러오거나 TTS로 암기 문장을 만들 수 있습니다. 문제와 힌트를 떠올리며 이동·운동 중에도 반복할 수 있습니다.

  • 녹음 파일 20초 미만
  • TTS 문장 50자 제한
  • 카드 모드에서도 음성 재생

두들링 학습

정답을 그대로 옮겨 적기보다, 낙서하듯 키워드·기호·선·그림을 직접 그리며 내용을 연결합니다. 손을 움직이며 떠올리는 과정을 반복 학습에 활용할 수 있습니다.

  • 키워드와 기호를 자유롭게 메모
  • 색과 선으로 내용의 관계를 연결
  • 스케치 영역에서 바로 두들링
STEP 03 · 정답 편집

그림과 이미지를 정답의 일부로

스케치에서 직접 그린 그림을 정답 편집에 넣고, 형광펜과 글자 굵기로 핵심 내용을 강조할 수 있습니다.

  • 두들링·도식·간단한 그래프 직접 작성
  • 스케치 이미지를 정답에 삽입
  • PC에서 캡처 후 Ctrl + V로 참고 이미지 추가
STEP 04 · 반복 설정

중요도·랜덤·순차·과목 묶음

문제마다 중요도를 지정하고 우선순위를 필터링할 수 있습니다. 한 과목뿐 아니라 여러 과목을 하나의 묶음으로 만들어 순차 또는 랜덤으로 학습할 수 있습니다.

  • 중요도 별표 필터
  • 랜덤 / 차례대로
  • 여러 과목 묶음 학습
  • 글자 크기·굵기·줄간격 설정
INSTALL · 설치하기

기기에 설치하면, 앱처럼 바로 시작할 수 있습니다.

마이서브노트는 PWA 방식의 웹 앱입니다. 별도의 설치 파일 없이 브라우저에서 바로 사용할 수 있고, 홈 화면·Dock·바탕화면에 설치해 일반 앱처럼 실행할 수 있습니다.

권장 사용 환경

원활한 이용을 위해 Chrome · Edge · Safari 최신 버전 사용을 권장합니다. 오래된 브라우저에서는 일부 기능이 정상적으로 작동하지 않을 수 있습니다.

Android · Chrome 권장iPhone / iPad · Safari 권장Windows · Chrome / Edge 권장Mac · Safari / Chrome / Edge

※ Mac에서 Safari의 웹 앱 설치 기능을 사용하려면 macOS Sonoma 14 이상이 필요합니다.

ANDROID APP · BETA

안드로이드 앱도 준비 중입니다.

브라우저에서 설치하는 PWA와 별도로 Android 전용 앱을 개발하고 있으며, Google Play 출시를 준비하고 있습니다.

ANDROID

Android

  1. Chrome에서 마이서브노트에 접속합니다.
  2. 주소창 오른쪽의 더보기(⋮)를 누릅니다.
  3. 홈 화면에 추가 → 설치를 선택합니다.
  4. 화면 안내에 따라 설치를 완료합니다.
iOS / iPadOS

iPhone · iPad

  1. Safari에서 마이서브노트에 접속합니다.
  2. 공유 버튼을 누릅니다.
  3. 홈 화면에 추가를 선택합니다.
  4. 웹 앱으로 열기를 켠 뒤 추가를 누릅니다.
WINDOWS

Windows PC

  1. Chrome 또는 Edge에서 마이서브노트에 접속합니다.
  2. 주소창의 앱 설치 아이콘을 누르거나 브라우저 메뉴를 엽니다.
  3. Chrome은 페이지를 앱으로 설치, Edge는 이 사이트를 앱으로 설치를 선택합니다.
  4. 설치를 눌러 완료합니다.
macOS

Mac

  1. Safari에서 마이서브노트에 접속합니다.
  2. 도구 막대의 공유 버튼을 누릅니다.
  3. Dock에 추가를 선택합니다.
  4. 추가를 누르면 Dock과 응용 프로그램에서 실행할 수 있습니다.
